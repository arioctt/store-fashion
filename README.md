# Concrete Signal — Industrial Streetwear Storefront

Demo static e‑commerce frontend for a streetwear brand.

## Features

- **Catalog** with filters (All, Hoodies, Tees, Outerwear, Pants, Accessories)
- **Search** and **sort** (price, newest)
- **Sale filter** toggle
- **Quick view** modal for product details
- **Cart** with add/remove and subtotal calculation
- **Saved items** (wishlist)
- **Newsletter signup** form (demo)
- **Responsive** design (mobile-first)
- **Dark industrial** aesthetic with lime accent

## Tech

- Plain HTML, CSS, JavaScript — no build step
- Images from Unsplash (public URLs)
- No backend or payment integration (demo only)

## Deploy

Enable **GitHub Pages** in repo settings → Pages → Source: `main` branch → Save.
Your site will be live at `https://arioctt.github.io/store-fashion/`.
